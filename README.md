# 🧠 TextLens AI

An AI-powered Natural Language Processing (NLP) platform for text analytics, visualization, and insights.

## 🚀 Features

- 📂 Upload your own CSV dataset
- 📊 Dataset Explorer
- ☁️ Word Cloud Generation
- 📈 Word Frequency Analysis
- 😊 Sentiment Analysis
- 🧠 Topic Modeling
- 📝 Text Summarization
- 🤖 AI Playground
- 📥 Download processed results

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- WordCloud
- NLTK
- VADER Sentiment
